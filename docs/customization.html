Custom Prompts

Customize editorial priorities, detail and focus. The plugin still requires validated JSON, source IDs and publication-date rules. The renderer controls news-item layout; use note templates for the surrounding document.

Summarization Prompt

Use {{NEWS_TEXT}} for source data and {{TOPIC}} for the topic. These preferences apply during structured summarization:

Example: Breaking News Focus
Analyze the following news and extract only breaking news and major announcements.
Ignore opinion pieces and minor updates.

News content:
{{NEWS_TEXT}}

Keep each factual summary to 2–3 sentences. Put interpretation in the analysis field and cite only the supplied source IDs. Preserve the required JSON structure.
Example: Investment Focus
Analyze this news from an investor's perspective:

{{NEWS_TEXT}}

Include source-supported financial metrics in the factual summary. Put possible market impact and risk interpretation in the analysis field. Preserve the required JSON structure.

AI Judge Prompt (Google providers only)

Controls how AI selects the best items from search results. Use {{NEWS_TEXT}} and {{TOPIC}}:

Example: Quality Filter
Select the 5 most significant news items about {{TOPIC}} from the list below.
Prioritize breaking news from reputable sources. Exclude opinion pieces and ads.

News list:
{{NEWS_TEXT}}

Tips

  • Be specific about what to include and exclude
  • Specify emphasis and detail; preserve the JSON schema and source/time rules. Use templates for note layout.
  • Set clear priorities for the AI
  • Test iteratively — start simple and refine
